# boki3drill

iOSアプリ「簿記3級ドリル（非公式）」の公開情報（サポート・プライバシーポリシー・利用規約）を管理するリポジトリです。GitHub Pages（`main` ブランチの `/docs`）で公開しています。

- サポート: https://taaaaho.github.io/boki3drill/
- プライバシーポリシー: https://taaaaho.github.io/boki3drill/privacy.html
- 利用規約: https://taaaaho.github.io/boki3drill/terms.html

ページの文言は `scripts/build_pages.py` で管理しています。編集後に `python3 scripts/build_pages.py` を実行してください。

本アプリは個人開発の非公式アプリであり、日本商工会議所・各地商工会議所その他の団体とは提携・協力・監修関係はありません。

ソースコードは非公開リポジトリ（`boki3drill-code`）で管理しています。
